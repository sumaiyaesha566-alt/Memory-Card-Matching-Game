# Memory-Card-Matching-Game
A cute and colorful Memory Card Matching Game for laptop and mobile browsers.

##📌Project Overview

Memory-Card-Matching-Game is a cute and colorful browser based game. The main objectives is to find and match pairs of identical cards.
Players flip two cards at a time. If the cards are identical, they remain open. If they are different, they turn back over. The game ends when all pairs are matched.
